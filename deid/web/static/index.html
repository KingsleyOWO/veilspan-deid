文件去識別化

文件內容會送往設定的模型端點。若要讓原文留在本機或內網，請選用該環境的模型。

遮蔽

檢查偵測到的個資，再下載維持原格式的遮蔽檔。可選擇全遮、遮一半或自訂要遮的字。

把檔案拖到這裡，或點一下選擇檔案

支援 Word（.docx）、Excel（.xlsx、.xlsm）與 PDF。

代號＋還原

把個資換成 [姓名1] 這類代號，再將代號版交給雲端處理。取得回覆後，可在這裡把代號換回原文。Word、Excel 可下載同格式的檔案和文字，PDF 則輸出文字。

把檔案拖到這裡，或點一下選擇檔案

支援 Word（.docx）、Excel（.xlsx、.xlsm）與 PDF。

會得到代號版和還原檔。還原檔含有原始個資且未加密，請留在本地。

還原雲端的回覆

貼上雲端回覆或上傳回覆檔，將代號換回原始資料。上傳的回覆檔處理完就會刪除。

上傳 Word 或 Excel：可以下載還原後的同一種檔案（格式不變，只把代號換回原文），也會顯示文字。上傳 PDF：只能還原成文字。圖片裡的文字不會讀取。
